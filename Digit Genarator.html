Manual

  1. Type a name and press Add or Enter. A random 6-digit code is assigned.
  2. Copy copies a code. Delete removes the row.
  3. In People, enter how many people you want in the PDF, then press Get PDF.
  4. If you ask for more people than the table has, extra rows are created automatically as Person 4, Person 5 and so on, each with its own code.
  5. Your table is saved in this browser.
